# Prexup | AI Real Estate CRM

Prexup is a modern, scalable, and responsive SaaS CRM designed for real estate agencies. It leverages AI for automated WhatsApp sales and provides a premium, information-dense interface for managing leads, properties, and finance.

## 🚀 Core Features
*   **AI-Powered WhatsApp Sales**: Automated lead qualification and response generation via Meta/Evolution API.
*   **Sales Pipeline**: Drag-and-drop Kanban board for deal tracking.
*   **Property Inventory**: High-end management with image uploads and advanced filtering.
*   **Finance Dashboard**: Real-time tracking of commissions and expenses.
*   **Multi-tenant Ready**: Designed for SaaS scalability with tenant isolation.

## 🛠 Tech Stack
*   **Frontend**: Next.js 14 (App Router), TailwindCSS, Framer Motion.
*   **Backend**: Node.js API Routes, AI Qualification Engine.
*   **Database**: MariaDB (Schema included in `db/schema.sql`).
*   **Icons**: Lucide React.

## 🎨 Design System
*   **Primary**: Electric Purple (#C000FF)
*   **Secondary**: Deep Royal Blue (#002080)
*   **Surface**: Glassmorphism with high-contrast dark mode.

## 📦 Getting Started
1. Install dependencies: `npm install`
2. Set up your MariaDB database using `db/schema.sql`.
3. Configure `.env` with your DB credentials.
4. Run: `npm run dev`
